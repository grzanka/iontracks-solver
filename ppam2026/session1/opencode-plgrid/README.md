# Vendored PLGrid opencode config

`opencode.json` and `.opencode/plugins/plgrid.js` here are copied verbatim
from [groundnuty/plgrid-llmlab-opencode](https://github.com/groundnuty/plgrid-llmlab-opencode)
(`AGENTS.md` deliberately skipped) so that setting up opencode against
PLGrid LLM Lab doesn't require cloning a second repo — see
[`../04-setup.md`](../04-setup.md).

That upstream repo has no LICENSE file. These two files are vendored here
purely for workshop convenience, with attribution kept intact — if you
need to update them, re-pull from upstream rather than hand-editing, and
check upstream's README and `research/` docs for anything that changed.
